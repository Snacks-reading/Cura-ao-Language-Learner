# Curaçao Luxury Conversational Coach — Native Audio Recording Script

## Purpose
This file is the audio production map for moving the app from synthetic practice audio to a genuinely accurate language trainer.

The web app should prefer real audio files from `/audio/` when present. Synthetic speech is only a fallback.

## Recording standard
- Record with a native or highly fluent Curaçao Papiamentu speaker for Papiamentu lines.
- Record Dutch lines with a Dutch speaker.
- Record Spanish lines with a Spanish speaker.
- Record each phrase twice:
  1. natural speed
  2. slow teacher speed
- File format: MP3, 128 kbps or higher.
- Trim silence at the beginning/end.
- Keep each clip under 8 seconds where possible.

## Required file naming
Each phrase should have two files:

- `audio/p001_normal.mp3`
- `audio/p001_slow.mp3`

Then continue sequentially.

## App behavior target
When a native clip exists:
- Slow mode plays `_slow.mp3`, pauses, repeats `_slow.mp3`, then speaks the English meaning.
- Normal mode plays `_normal.mp3`, then English meaning.
- Local mode plays `_normal.mp3` only.

When a clip is missing:
- App displays: “Native audio missing — using phonetic fallback.”
- App uses the phonetic fallback already built into the app.
